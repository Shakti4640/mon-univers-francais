Quick Reference

The plus-que-parfait describes an action that happened BEFORE another past action. It is the "past of the past."

English equivalent: had done / had been / had eaten, etc.

Formation:
SUBJECT + AUXILIARY (avoir or être) in IMPARFAIT + PAST PARTICIPLE

With AVOIR:

Subjectavoir (imparfait)+ past participle
j'avaisparlé
tuavaisparlé
il/elle/onavaitparlé
nousavionsparlé
vousaviezparlé
ils/ellesavaientparlé

With ÊTRE:

Subjectêtre (imparfait)+ past participle
jeétaisallé(e)
tuétaisallé(e)
il/elle/onétaitallé(e)(s)
nousétionsallé(e)s
vousétiezallé(e)(s)
ils/ellesétaientallé(e)s

⚠️ Same rules as passé composé:

  • Same verbs use ÊTRE (DR MRS VANDERTRAMP + reflexives)
  • Same agreement rules apply
  • Same irregular past participles

Quick Reference — When to Use the Plus-que-parfait

The plus-que-parfait expresses an action completed BEFORE another past action.

Timeline:

PLUS-QUE-PARFAIT ←――――― PASSÉ COMPOSÉ/IMPARFAIT ←――――― PRÉSENT
(had done)                 (did / was doing)                (do/does)

Common patterns:

PatternExample
PQP + quand + PCJ'avais déjà mangé quand il est arrivé.
PC + parce que + PQPIl était fatigué parce qu'il avait travaillé toute la nuit.
PC + que + PQPJ'ai compris qu'elle était partie.
Après que + PQPAprès qu'il avait fini, il est sorti.

Quick Reference — Plus-que-parfait with Reflexive Verbs

All reflexive verbs use ÊTRE in the plus-que-parfait (same as passé composé).

SubjectExample: se lever
jem'étais levé(e)
tut'étais levé(e)
ils'était levé
elles'était levée
ons'était levé(s)
nousnous étions levé(e)s
vousvous étiez levé(e)(s)
ilss'étaient levés
elless'étaient levées

⚠️ Same agreement rules as passé composé reflexives:

  • Agreement with the reflexive pronoun when it's the direct object
  • No agreement when there's a separate direct object after the verb
