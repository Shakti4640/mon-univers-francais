  • How do you decode a prompt that has NO concrete topic?

🟡 HOW TO APPROACH IT

Step 1: Understand WHY Abstract Prompts Are Different

CONCRETE PROMPT (Chapters 1–23 trained for this):
  "Le télétravail est-il bénéfique?"
  → TOPIC: Clear (remote work)
  → THEME: Identifiable (Theme 5 — Work)
  → VOCABULARY BANK: Activatable (Chapter 18)
  → ARGUMENTS: Accessible (real-world examples available)
  → POSITION: Binary choice possible (yes/no/nuanced)

ABSTRACT PROMPT (Chapter 24 addresses this):
  "La liberté individuelle peut-elle exister sans limites?"
  → TOPIC: Vague (freedom? limits? individual vs. collective?)
  → THEME: None of the 10 standard themes directly applies
  → VOCABULARY BANK: No single bank matches
  → ARGUMENTS: Must be CONSTRUCTED from abstract reasoning
  → POSITION: Binary choice feels INADEQUATE
  → KEY TERMS: Ambiguous (must be DEFINED before arguing)

Step 2: Identify the 4 Types of Unpredictable Prompts

TYPE 1: ABSTRACT PHILOSOPHICAL PROMPT
  → Asks about a CONCEPT: freedom, justice, happiness, truth, progress
  → "Le bonheur dépend-il uniquement de nous-mêmes?"
  → "La vérité est-elle toujours bonne à dire?"
  → "Le progrès est-il synonyme de bonheur?"

TYPE 2: MULTI-LAYERED PROMPT
  → Contains TWO or more concepts that must be RELATED
  → "La liberté individuelle peut-elle exister SANS LIMITES?"
    (freedom + limits → relationship between them)
  → "L'art est-il un luxe ou une nécessité?"
    (art + luxury + necessity → three concepts to navigate)

TYPE 3: PARADOXICAL PROMPT
  → Presents a statement that seems to CONTRADICT itself
  → "Peut-on être libre en obéissant aux lois?"
    (freedom + obedience → apparent contradiction)
  → "Le doute est-il une force ou une faiblesse?"
    (doubt as both positive and negative)

TYPE 4: OPEN-ENDED SOCIETAL PROMPT (unusual angle)
  → Addresses a familiar topic but from an UNEXPECTED angle
  → "La technologie nous rend-elle plus humains ou moins humains?"
    (technology → but the angle is "humanity," not "convenience")
  → "L'éducation peut-elle être neutre?"
    (education → but the angle is "neutrality," not "quality")

Step 3: Understand the Critical Difference — Definition Before Argumentation

  • In concrete prompts → The terms are clear → You argue immediately
  • In abstract prompts → The terms are AMBIGUOUS → You must DEFINE them before arguing
  • Defining terms is the SINGLE MOST IMPORTANT skill for abstract prompts
  • Without definition → Your argument floats in vagueness → The evaluator cannot follow your logic
WHY DEFINITION IS ESSENTIAL:

PROMPT: "La liberté individuelle peut-elle exister sans limites?"

WITHOUT DEFINITION:
  "La liberté est importante. Les limites sont nécessaires.
   Donc la liberté ne peut pas exister sans limites."
  → WHAT KIND of freedom? Political? Personal? Economic?
  → WHAT KIND of limits? Legal? Moral? Physical? Social?
  → The argument is VACUOUS because the terms mean ANYTHING

WITH DEFINITION:
  "La liberté individuelle — entendue comme la capacité de chaque citoyen
   à agir selon sa volonté — ne saurait s'exercer sans un cadre qui protège
   les droits d'autrui."
  → "Liberté individuelle" = DEFINED (capacity to act according to one's will)
  → "Limites" = DEFINED (framework protecting others' rights)
  → NOW the argument has SOLID GROUND to stand on

Step 4: Understand the Modified Pipeline for Abstract Prompts

  • The 8-step pipeline (Chapter 20) needs ADAPTATION, not replacement:
STANDARD PIPELINE (Chapter 20):          MODIFIED PIPELINE (Chapter 24):

Step 1: Prompt analysis                  Step 1: Prompt analysis
Step 2: Position selection               Step 2: TERM DEFINITION ← NEW
Step 3: Theme detection + vocab          Step 3: Position selection (AFTER definition)
Step 4: Argument planning                Step 4: CROSS-THEME vocab activation ← MODIFIED
Step 5: Introduction writing             Step 5: Argument planning
Step 6: Body writing                     Step 6: Introduction WITH definitions ← MODIFIED
Step 7: Conclusion writing               Step 7: Body writing
Step 8: Review                           Step 8: Conclusion writing

  • Key change: The introduction INCLUDES definitions

🟢 HOW CAN WE SOLVE IT

THE COMPLETE ABSTRACT PROMPT FRAMEWORK

🔷 FRAMEWORK ELEMENT 1: THE TERM DEFINITION SYSTEM

How to define abstract terms clearly, precisely, and quickly within a TEF response

1A → Identify the Key Terms That NEED Definition

  • Not EVERY word needs definition — only the AMBIGUOUS, ABSTRACT ones
PROMPT: "La liberté individuelle peut-elle exister sans limites?"

TERM ANALYSIS:
  "La liberté individuelle" → ABSTRACT → Needs definition ✅
  "peut-elle" → Grammatical → No definition needed ❌
  "exister" → Clear verb → No definition needed ❌
  "sans" → Clear preposition → No definition needed ❌
  "limites" → ABSTRACT → Needs definition ✅

TERMS TO DEFINE: "liberté individuelle" + "limites"
MAXIMUM TERMS TO DEFINE: 2 (in a 220-word response, you cannot define 3+ terms)

Decision Rule for Identifying Terms That Need Definition:

Term TypeNeeds Definition?Example
Abstract concept (freedom, justice, happiness, truth)✅ YES — always"La liberté," "le bonheur," "la justice"
Relative concept (progress, success, limits)✅ YES — meaning shifts by context"Le progrès," "la réussite," "les limites"
Concrete noun (school, phone, car)❌ NO — meaning is clear"L'école," "le téléphone"
Action verb (ban, allow, encourage)❌ NO — meaning is clear"Interdire," "autoriser"
Relational word (with, without, between)❌ NO — but the RELATIONSHIP may need clarification"Sans," "entre," "malgré"

1B → The 5 Definition Techniques for TEF

Technique 1: FUNCTIONAL DEFINITION (What It Does)

Defining a concept by its FUNCTION or ROLE

French StructureExample
[Term], c'est-à-dire [function]La liberté individuelle, c'est-à-dire la capacité d'agir selon sa propre volonté...
[Term], entendu(e) comme [function]La liberté, entendue comme le droit de chacun à disposer de soi-même...
Par [term], on entend [function]Par liberté individuelle, on entend le pouvoir d'un individu de faire ses propres choix.
Technique 2: OPPOSITION DEFINITION (What It Is NOT)

Defining a concept by contrasting it with what it IS NOT

French StructureExample
[Term] ne se résume pas à [misconception], mais désigne plutôt [true meaning]La liberté ne se résume pas à l'absence de contraintes, mais désigne plutôt la capacité d'agir de manière éclairée.
Il ne faut pas confondre [term] avec [similar concept]Il ne faut pas confondre la liberté individuelle avec l'individualisme : l'une est un droit, l'autre est une posture.
Loin de se limiter à [narrow meaning], [term] englobe [broader meaning]Loin de se limiter à la liberté de mouvement, la liberté individuelle englobe la pensée, l'expression et le choix de vie.
Technique 3: CONTEXTUAL DEFINITION (What It Means HERE)

Defining a concept specifically within the context of the debate

French StructureExample
Dans le contexte de [debate], [term] renvoie à [specific meaning]Dans le contexte de ce débat, les "limites" renvoient aux cadres légaux et moraux qui régissent la vie en société.
Tel qu'il est envisagé ici, [term] désigne [specific meaning]Telle qu'elle est envisagée ici, la liberté désigne le droit fondamental à l'autodétermination.
Au sens où nous l'entendons, [term] fait référence à [meaning]Au sens où nous l'entendons, la liberté fait référence à l'exercice autonome de la volonté individuelle.
Technique 4: EXAMPLE-BASED DEFINITION (What It Looks Like)

Defining a concept through a concrete illustration

French StructureExample
[Term] — comme le fait de [concrete example]La liberté individuelle — comme le fait de choisir sa profession, son lieu de vie ou ses convictions...
[Term] se manifeste par exemple dans [concrete case]Cette liberté se manifeste par exemple dans le droit de s'exprimer sans crainte de répression.
Technique 5: PHILOSOPHICAL DEFINITION (Traditional/Scholarly)

Defining a concept by referencing its intellectual tradition

French StructureExample
Depuis [thinker/tradition], [term] est conçu(e) commeDepuis les Lumières, la liberté est conçue comme un droit naturel et inaliénable.
Au sens philosophique du terme, [term] désigneAu sens philosophique du terme, la liberté désigne la capacité de se déterminer soi-même.
Traditionnellement, [term] s'entend commeTraditionnellement, la liberté s'entend comme l'absence de coercition extérieure.

1C → Where to Place Definitions in Your Response

PLACEMENT OPTION A: INSIDE THE INTRODUCTION (Recommended)
  Sentence 1: Context
  Sentence 2: Definition of key term(s)
  Sentence 3: Problématique + Thesis
  → Definition is INTEGRATED into the introduction flow
  → The reader has clear terms BEFORE the argument begins

PLACEMENT OPTION B: AT THE START OF BODY 1
  Introduction: Context + Problématique + Thesis (without definition)
  Body 1, Sentence 1: "Définissons d'abord ce que l'on entend par..."
  → More explicit → But uses valuable body paragraph space
  → Use ONLY if the definition is complex and needs a full sentence

PLACEMENT OPTION C: WOVEN THROUGHOUT (Advanced)
  Introduction: Quick definition of Term 1
  Body 1: Develops based on Definition 1
  Body 2: Introduces refined/alternative definition of Term 1 (antithèse angle)
  Synthèse: Proposes a THIRD definition that transcends both
  → Most sophisticated → The DEFINITIONS themselves become the argument
  → Recommended for C1 targeting on philosophical prompts

1D → Definition Integration in Introduction — Full Example

Prompt: "La liberté individuelle peut-elle exister sans limites?"

Introduction WITHOUT Definition (Weak):

La liberté est un sujet important. Beaucoup de gens en parlent. Peut-elle exister sans limites? Je vais donner mon avis.

→ "Liberté" = undefined → Vague
→ "Limites" = undefined → Vague
→ The entire response will float in abstraction

Introduction WITH Definition (Strong):

La liberté individuelle — entendue comme la capacité de chaque citoyen à agir selon sa volonté et ses convictions — constitue un pilier des sociétés démocratiques. Toutefois, cette liberté peut-elle véritablement s'exercer sans aucune limite, ou nécessite-t-elle un cadre pour demeurer viable? Il me semble que la liberté, loin d'être incompatible avec les limites, ne peut pleinement exister que grâce à elles.

→ "Liberté individuelle" = DEFINED (Technique 1: functional)
→ "Limites" = CONTEXTUALIZED (implied: cadre for viability)
→ Thesis = CLEAR (freedom needs limits to fully exist)
→ The evaluator KNOWS exactly what you are arguing about
→ Word count: 64 words — slightly long but justified for an abstract prompt

🔷 FRAMEWORK ELEMENT 3: THE ABSTRACT ARGUMENT CONSTRUCTION SYSTEM

How to build arguments about CONCEPTS rather than concrete topics

3A → The 4 Argument Sources for Abstract Prompts

SOURCE 1: LOGICAL REASONING (Pure Logic)
  → If freedom has no limits → One person's freedom can destroy another's
  → Therefore → Unlimited freedom is self-contradictory
  → This is DEDUCTIVE reasoning → No external example needed

SOURCE 2: CONCRETE EXAMPLES APPLIED TO ABSTRACT CONCEPTS
  → Freedom of speech (abstract) → Hate speech laws (concrete)
  → Individual liberty (abstract) → Mask mandates during pandemic (concrete)
  → Happiness (abstract) → Wealth vs. relationships research (concrete)
  → ABSTRACT prompts NEED concrete examples to ground the reasoning

SOURCE 3: HISTORICAL/CULTURAL REFERENCES
  → The French Revolution (liberté, égalité, fraternité)
  → The Universal Declaration of Human Rights (1948)
  → Philosophical traditions (Rousseau's social contract)
  → These references add INTELLECTUAL DEPTH and ETHOS (Chapter 22 Weapon 7B)

SOURCE 4: SOCIETAL OBSERVATION
  → "On observe que dans les sociétés sans cadre légal..."
  → "L'histoire montre que les libertés absolues ont conduit à..."
  → "Les démocraties modernes illustrent la nécessité de..."
  → Observation of real societies applied to abstract questions

3B → The "Abstraction Ladder" Technique

Moving UP and DOWN between abstract concepts and concrete examples within the same argument

THE ABSTRACTION LADDER:

TOP (Most abstract):     PRINCIPLE / CONCEPT
                              ↕
MIDDLE (Semi-abstract):  SOCIETAL APPLICATION
                              ↕
BOTTOM (Most concrete):  SPECIFIC EXAMPLE

EXAMPLE FOR "FREEDOM AND LIMITS":

TOP: "La liberté individuelle nécessite un cadre pour exister pleinement."
  → Pure principle → Abstract

MIDDLE: "Dans les sociétés démocratiques, les lois encadrent cette liberté
         afin de protéger les droits de chacun."
  → Applied to society → Semi-abstract

BOTTOM: "Ainsi, la liberté d'expression, bien que fondamentale, est limitée
         par les lois contre la diffamation et l'incitation à la haine."
  → Concrete example → Grounded

THE RULE:
  → Every abstract argument must DESCEND the ladder at least once
  → Start at TOP → Move to MIDDLE or BOTTOM → Return to TOP
  → This gives the evaluator BOTH depth of thought AND concrete grounding
  → An argument that stays at TOP only → Too vague → Evaluator cannot assess reasoning
  → An argument that stays at BOTTOM only → Too concrete → Misses the philosophical dimension

3C → Building a Full Argument Using the Abstraction Ladder

Argument for: "Freedom needs limits"

[TOP] La liberté individuelle, aussi précieuse soit-elle, ne saurait s'exercer de manière absolue sans menacer l'harmonie sociale. [MIDDLE] En effet, dans toute société organisée, la liberté de chacun trouve sa limite là où commence celle d'autrui — un principe fondamental du contrat social. [BOTTOM] À titre d'exemple, la liberté d'expression, pourtant considérée comme un droit inaliénable, est encadrée par des lois interdisant la diffamation et l'incitation à la haine. [TOP — RETURN] Cela démontre que les limites, loin de restreindre la liberté, en garantissent l'exercice équitable pour tous.

🔶 FRAMEWORK ELEMENT 4: THE ABSTRACT PROMPT THÈSE-ANTITHÈSE-SYNTHÈSE ADAPTATION

How to structure a dialectical response (Chapter 21) for abstract content

4A → The Concept-Based Thèse-Antithèse-Synthèse

FOR CONCRETE PROMPTS (Chapters 14, 21):
  Thèse: Side A of a practical debate
  Antithèse: Side B of the same practical debate
  Synthèse: Higher perspective transcending both sides

FOR ABSTRACT PROMPTS (Chapter 24):
  Thèse: DEFINITION 1 of the key term → Argument based on this definition
  Antithèse: DEFINITION 2 of the key term → Argument based on THIS definition
  Synthèse: DEFINITION 3 that INTEGRATES both → Transcendent understanding

THE DEFINITIONS THEMSELVES BECOME THE ARGUMENT

4B → Full Example: "La liberté individuelle peut-elle exister sans limites?"

THÈSE (Definition 1: Freedom = absence of constraints):
  → If freedom means having NO external constraints...
  → Then limits DESTROY freedom by definition
  → Therefore: Freedom cannot coexist with limits (from this definition)
  → Example: A prisoner has limits → A prisoner is not free

ANTITHÈSE (Definition 2: Freedom = capacity to act meaningfully):
  → If freedom means the capacity to make MEANINGFUL choices...
  → Then limits actually ENABLE freedom by preventing chaos
  → Therefore: Freedom REQUIRES limits to function (from this definition)
  → Example: Traffic laws limit movement → But ENABLE safe travel for all

SYNTHÈSE (Definition 3: Freedom = self-determined action within a just framework):
  → The apparent contradiction dissolves when we redefine freedom
  → Freedom is neither pure absence of constraints NOR pure obedience to rules
  → Freedom is the capacity to act according to one's will WITHIN a framework
     that protects the same capacity for others
  → This is Chapter 21 Type 2 (Reframing) → The definition ITSELF is the transcendence

4C → The Full Response for the Abstract Prompt

INTRODUCTION (with definitions):

La notion de liberté individuelle occupe une place centrale dans la pensée démocratique. Mais que signifie véritablement "être libre"? S'agit-il de l'absence totale de contraintes, ou plutôt de la capacité à agir de manière autonome et éclairée? Il me semble que la liberté, loin d'être incompatible avec les limites, ne peut pleinement s'épanouir que dans un cadre qui en garantit l'exercice équitable.

Word count: 62 words
Tools: Ch.10 (intro formula) + Ch.24 (Technique 1 functional definition + Technique 2 opposition definition) + Ch.22 Weapon 1 (rhetorical questions: "Que signifie...? S'agit-il...?") + Ch.23 (soutenu register: "véritablement," "éclairée")

BODY 1 — THÈSE (Freedom seems to require no limits):

D'une part, concevoir la liberté comme l'absence de toute contrainte conduit à penser que les limites en constituent la négation. En effet, un individu soumis à des règles imposées voit sa marge de manœuvre restreinte. Cela semble confirmer l'idée selon laquelle toute limitation porte atteinte à l'essence même de la liberté.

Word count: 48 words
Tools: Ch.7 ("D'une part") + Ch.24 (Definition 1 applied) + Ch.19 Tool 5 ("En effet") + Ch.19 Tool 1 ("Cela") + Ch.15 (causal: "conduit à penser") + Ch.23 ("marge de manœuvre," "porte atteinte à l'essence")

BODY 2 — ANTITHÈSE (Freedom actually needs limits):

D'autre part, il est indéniable qu'une liberté sans bornes conduirait au chaos. En l'absence de cadre, la liberté des uns empiéterait inévitablement sur celle des autres. Ainsi, les lois contre la diffamation ne restreignent pas la liberté d'expression : elles en protègent l'exercice pour chaque citoyen. Dès lors, les limites apparaissent non comme des entraves, mais comme des conditions nécessaires au vivre-ensemble.

Word count: 64 words
Tools: Ch.13 ("D'autre part") + Ch.16 (concession "il est indéniable que") + Ch.9 (example: defamation laws) + Ch.15 (causal: "conduirait → empiéterait → Dès lors") + Ch.22 Weapon 4 (antithesis: "non comme des entraves, mais comme des conditions") + Ch.19 Tools 5, 4

BODY 3 — SYNTHÈSE (Reframing the definition):

Au-delà de cette opposition, le véritable enjeu réside dans notre conception même de la liberté. Celle-ci ne se résume ni à l'absence de contraintes ni à la simple obéissance aux règles. La liberté véritable consiste à se déterminer soi-même au sein d'un cadre juste qui préserve cette même capacité pour autrui. C'est dans cet équilibre que la liberté trouve sa pleine expression.

Word count: 58 words
Tools: Ch.21 Type 2 (Reframing synthèse) + Ch.24 (Definition 3 — transcendent) + Ch.22 Weapon 2 (emphatic: "C'est dans cet équilibre que...") + Ch.17 Type 3 ("qui préserve") + Ch.19 Tools 2, 3 + Ch.23 (soutenu: "se déterminer soi-même," "pleine expression")

CONCLUSION:

En définitive, la liberté individuelle et les limites ne s'opposent qu'en apparence. J'estime que c'est précisément grâce à un cadre équitable que chacun peut exercer sa liberté de manière authentique et responsable.

Word count: 31 words
Tools: Ch.11 (conclusion formula) + Ch.23 ("J'estime que" — personal frame closing) + Ch.22 Weapon 5 (litote implied: "ne s'opposent qu'en apparence")

🔵 WHAT COULD BE DONE

Option A: Treat Abstract Prompts Like Concrete Prompts

  • → Skip definitions → Jump to arguments → Hope it works
  • → Result: Vague, floating arguments → Evaluator lost → Low score
  • → NOT recommended

Option B: Define Every Single Word in the Prompt

  • → Over-defining → Wastes word count → Body arguments underdeveloped
  • → Define 2 key terms maximum → Spend the rest on argumentation
  • → Partially useful but over-applied

Option C: Apply the Modified Pipeline With Term Definition + Cross-Theme Vocabulary + Abstraction Ladder

  • → Systematic approach → Works for ANY abstract prompt
  • → Definitions ground the argument → Cross-theme vocabulary fills the gaps → Abstraction ladder provides structure
  • → THIS IS THE CORRECT APPROACH

Option D: Avoid Taking a Position and Just Explore the Concept

  • → Some candidates think abstract prompts invite "exploration" without positioning
  • → WRONG → TEF Section B ALWAYS requires a position (Dimension 1 — consigne)
  • → You MUST state an opinion even on philosophical prompts
  • → NOT recommended

✅ WHAT SHOULD DO

1. Build the "Emergency Decode" Reflex for Unexpected Prompts

THE 90-SECOND EMERGENCY DECODE:

SECOND 0–20: READ the prompt twice
  → Identify: What CONCEPTS are present?
  → Identify: What RELATIONSHIP between concepts is being asked about?

SECOND 20–40: DEFINE the key terms (mentally)
  → "What does Term 1 mean in this context?"
  → "What does Term 2 mean in this context?"
  → "What is the TENSION between them?"

SECOND 40–60: FIND your position
  → "Do I think the answer is YES, NO, or NUANCED?"
  → For philosophical prompts: NUANCED is almost always the best choice
  → Identify which SYNTHÈSE TYPE (Chapter 21) fits best

SECOND 60–90: MAP to themes
  → "Which of my 10 theme vocabulary banks have relevant words?"
  → "Which UNIVERSAL ABSTRACT words do I need?"
  → Select 8–10 vocabulary items

→ After 90 seconds, you have: Definition + Position + Vocabulary
→ Now proceed to argument planning (Step 5 of modified pipeline)

5. Handle Paradoxical Prompts Specifically

PARADOXICAL PROMPT: "Peut-on être libre en obéissant aux lois?"

THE PARADOX: Freedom = no constraints / Obedience = accepting constraints
  → These seem CONTRADICTORY → How can you have both?

THE RESOLUTION METHOD:
  Step 1: Show that the paradox exists (acknowledge it)
    → "De prime abord, liberté et obéissance semblent inconciliables."
  
  Step 2: Show that the paradox is based on a NARROW definition
    → "Cette contradiction apparente repose sur une conception réductrice
       de la liberté comme absence totale de contraintes."
  
  Step 3: Propose a BROADER definition that resolves the paradox
    → "Or, si l'on conçoit la liberté comme la capacité de vivre
       en société de manière autonome et protégée, alors les lois,
       loin d'entraver cette liberté, en constituent le fondement."
  
  Step 4: Provide a concrete anchor
    → "Le code de la route, par exemple, limite notre vitesse mais
       garantit la sécurité de tous — et donc notre liberté de circuler."

THIS IS ALWAYS Type 2 (Reframing) Synthèse:
  → The paradox is APPARENT, not real
  → It dissolves when the terms are properly defined
  → The "resolution" IS the synthèse

❌ WHAT SHOULD NOT DO

1. Do NOT Panic and Abandon Your Structure

PANIC RESPONSE:
  "I don't recognize this topic → I'll just write whatever comes to mind"
  → Unstructured stream of consciousness → ALL dimensions fail

CORRECT RESPONSE:
  "I don't recognize this topic → I'll use the modified pipeline"
  → Definition → Position → Arguments → Structure maintained
  → Even if the CONTENT is imperfect, the STRUCTURE saves your score
  → Refer to Chapter 20: "Complete and adequate > Incomplete and polished"

2. Do NOT Over-Define at the Expense of Argumentation

❌ DEFINITION OVERLOAD (100 words on definitions, 120 words on arguments):
  → The response becomes a GLOSSARY, not an argument
  → Dimension 1 penalty: "Did not develop arguments sufficiently"

✅ BALANCED DEFINITION (40 words on definitions, 180 words on arguments):
  → Definitions are CONCISE but CLEAR
  → Arguments receive the majority of space
  → Both definition AND argumentation serve the response

RULE: Definitions should occupy no more than 20–25% of total word count
  → In a 220-word response → Maximum 50 words for definitions
  → The rest is argumentation, examples, synthèse, conclusion

3. Do NOT Use Personal Anecdotes as Your Main Evidence

❌ PERSONAL ANECDOTE AS MAIN EVIDENCE:
  "Quand j'étais petit, ma mère me disait toujours que la liberté est importante.
   Un jour, j'ai voulu sortir tard et elle m'a dit non. J'ai compris que la liberté
   a des limites."
  → This is a NARRATIVE, not an argument
  → It is personal, not universal
  → It addresses the topic at A2 level, not B2/C1

✅ SOCIETAL EXAMPLE AS EVIDENCE:
  "La liberté d'expression, bien que fondamentale, est encadrée par des lois
   interdisant la diffamation — ce qui illustre la nécessité de concilier
   liberté individuelle et protection collective."
  → This is ANALYTICAL, not narrative
  → It is universal, not personal
  → It addresses the topic at B2/C1 level

4. Do NOT Treat Abstract Prompts as Invitations to Philosophize Without Structure

❌ UNSTRUCTURED PHILOSOPHIZING:
  "La liberté est un concept complexe. Beaucoup de philosophes en ont parlé.
   Rousseau disait que l'homme est né libre. Mais Sartre disait que nous sommes
   condamnés à être libres. La question est difficile. Il y a beaucoup de
   perspectives différentes."
  → Name-drops philosophers → But makes NO argument
  → Mentions complexity → But provides NO resolution
  → The evaluator reads: "This candidate knows ABOUT philosophy but cannot DO philosophy"

✅ STRUCTURED PHILOSOPHICAL ARGUMENT:
  → Definition → Thèse → Antithèse → Synthèse → Conclusion
  → Same structure as Chapter 21 → Applied to abstract content
  → The structure FORCES you to argue, not just explore

5. Do NOT Ignore the "Justifiez" Instruction

  • Even philosophical prompts include "Justifiez votre point de vue"
  • This means you MUST:
    • → State a clear position (Chapter 3)
    • → Provide arguments (Chapters 9, 15)
    • → Include examples (Chapter 9 + Concrete Anchor Rule)
  • Merely "exploring" the concept without justification → Dimension 1 penalty

6. Do NOT Define Terms Using Circular Logic

❌ CIRCULAR DEFINITION:
  "La liberté, c'est être libre."
  "Les limites sont ce qui limite."
  → The definition uses the SAME WORD it is defining
  → It tells the reader NOTHING new

✅ NON-CIRCULAR DEFINITION:
  "La liberté, c'est la capacité d'agir selon sa propre volonté."
  "Les limites désignent les cadres légaux et moraux qui régissent la vie en société."
  → Each definition uses DIFFERENT words than the term being defined
  → The reader gains NEW understanding

7. Do NOT Use Only One Level of the Abstraction Ladder

❌ ONLY TOP (pure abstraction):
  "La liberté est un droit. Les limites sont nécessaires. Le cadre est important.
   L'équilibre est essentiel."
  → Every sentence is abstract → No grounding → Evaluator cannot assess reasoning

❌ ONLY BOTTOM (pure examples):
  "The speed limit is 130 km/h. Hate speech is illegal. You cannot smoke indoors."
  → Every sentence is concrete → No conceptual thinking → Misses the philosophical dimension

✅ LADDER MOVEMENT (TOP → BOTTOM → TOP):
  "La liberté nécessite un cadre [TOP]. Ainsi, les lois contre la diffamation
   encadrent la liberté d'expression [BOTTOM]. Cela confirme que les limites
   ne restreignent pas la liberté mais en protègent l'exercice équitable [TOP]."
  → Moves between levels → Both depth AND grounding → Maximum score

  → For concrete prompts: Works instantly
  → For abstract prompts: FAILS → No theme detected → Panic

THE FIX (Chapter 24):

  → MODIFY Step 3 to Cross-Theme Activation
  → The pipeline ADAPTS without being replaced

How the Evaluator Assesses Abstract Prompt Responses

CRITERION 1: Does the candidate DEFINE key terms?

CRITERION 2: Does the candidate provide CONCRETE examples for abstract claims?

  → Abstract prompts REVEAL the strongest candidates
  → Weak candidates panic and produce disorganized responses
  → Strong candidates use definitions + structure to DOMINATE
  → The score SPREAD is wider on abstract prompts than concrete ones
  → THIS IS YOUR OPPORTUNITY — if you are prepared, you SHINE

The Definition-Argumentation Feedback Loop

DEFINITION shapes ARGUMENTATION:

  → Definition 1 (absence of constraints) → Arguments about removing restrictions
  → Definition 2 (capacity for meaningful choice) → Arguments about enabling conditions
  → The SAME PROMPT generates COMPLETELY DIFFERENT arguments depending on definition

ARGUMENTATION shapes DEFINITION:
  → As you argue, your understanding of the term DEEPENS
  → The synthèse often REDEFINES the term based on what the arguments revealed
  → This is the highest level of intellectual engagement

THE FEEDBACK LOOP:
  Definition → Arguments → Deeper Understanding → Refined Definition → Stronger Arguments
  → This loop happens NATURALLY when you follow the Chapter 24 framework
  → It is what the evaluator recognizes as "intellectual maturity"

🕳️ COMMON PITFALLS AND FAILURE MODES

Pitfall 1: The Definition Desert

  • No definition at all → Arguments float in vagueness
  • Detection: After writing the introduction, ask: "Would a reader know EXACTLY what I mean by [key term]?"
  • Solution: Add a definition using one of the 5 techniques

Pitfall 2: The Concrete Avoidance

  • Writing ONLY in abstract terms without any concrete examples
  • Detection: After writing a body paragraph, ask: "Is there at least ONE specific, real-world reference?"
  • Solution: Add a concrete anchor from the bank provided above

Pitfall 3: The Philosophical Name-Drop

  • Mentioning Rousseau, Voltaire, or Sartre without USING their ideas in the argument
  • → "Comme disait Rousseau..." → Then what? If you cannot explain HOW this supports your argument, do not mention it
  • Rule: Only reference thinkers if you can connect their idea DIRECTLY to your argument in the same sentence
  • → ✅ "Comme le soulignait Rousseau, l'homme naît libre, mais c'est le contrat social qui rend cette liberté viable — ce qui confirme la nécessité de limites."
  • → ❌ "Rousseau a parlé de la liberté. C'est un philosophe important."

Pitfall 4: The False Binary on a Philosophical Prompt

  • Treating "La liberté peut-elle exister sans limites?" as a simple YES/NO question
  • → "Oui, la liberté peut exister sans limites" → Too simplistic → Misses the complexity
  • → "Non, la liberté ne peut pas exister sans limites" → Better but still binary
  • → "La liberté et les limites ne s'opposent qu'en apparence — la vraie question est..." → DIALECTICAL → C1 level
  • Rule: Philosophical prompts almost ALWAYS call for a nuanced/synthèse approach

Pitfall 5: The Definition Drift

  • Defining a term in the introduction → Then arguing based on a DIFFERENT definition in the body
  • → Introduction: "La liberté, c'est l'absence de contraintes"
  • → Body: "La liberté nécessite un cadre pour fonctionner"
  • → These are CONTRADICTORY definitions → The argument collapses
  • Detection: After writing the body, re-read your definition → Does the body MATCH it?
  • Exception: If you DELIBERATELY use different definitions for thèse vs. antithèse (Section 4B above) → This is INTENTIONAL and must be SIGNALED clearly

Pitfall 6: The Vocabulary Vacuum

  • Not knowing what to write because no theme bank matches
  • → Freezing → Writing simple sentences → A2-level vocabulary
  • Prevention: Memorize the Universal Abstract Vocabulary Bank (Framework Element 2B)
  • → These 40+ words work for ANY abstract prompt
  • → They are your EMERGENCY vocabulary supply

Pitfall 7: The Endless Abstraction

  • Every sentence at the TOP of the abstraction ladder → No descent
  • → "Freedom is important. Limits are necessary. Balance is essential. Values matter."
  • → The evaluator reads: "This candidate is stating truisms, not arguing"
  • Solution: Force yourself DOWN the ladder → "For example..." / "Ainsi..." / "En témoigne..."

Pitfall 8: The Wrong Tone for Philosophy

  • Writing about abstract concepts in the same tone as concrete prompts
  • → Concrete prompts allow direct, practical language
  • → Abstract prompts require MORE nuanced, measured language
  • → Chapter 23 register is even MORE critical for abstract prompts
  • → "Ne saurait" / "il convient de" / "loin de se résumer à" → Essential for philosophical tone
