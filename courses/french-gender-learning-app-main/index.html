The Big Idea

Everything you need to know before you learn anything else
In French, every single noun is either masculine or feminine. There is no neutral. Gender determines which article (the/a) you use, and changes adjective endings. The gender often has nothing to do with the real world — le livre (book) is masculine, la table (table) is feminine, for no logical reason.

🔵 Masculine

🩷 Feminine

unea / an
de lasome
lesthe (plural)
Before any noun starting with a vowel or silent H, both le and la become l' — you can't tell gender from the article alone.
→ l'homme (M), l'école (F), l'arbre (M), l'eau (F)
01
Always learn nouns WITH their article
Don't memorize "livre". Memorize "le livre". The article is part of the word.
02
Use endings as hints, not rules
Endings give you ~80–95% accuracy. There are always exceptions — always confirm with a dictionary.
03
Context rescues you
Surrounding adjectives and pronouns reveal the gender: mon beau jardin → masculine.
04
Accept imperfection
Native French speakers sometimes hesitate too. Getting the meaning across matters more than perfect gender.

Plural Formation

How nouns change from singular to plural
General rule: Add -s to the singular. That's it for ~80% of words. But French has 6 special patterns worth knowing.
Regular → + s Most words: le livre → les livres  |  la table → les tables
-s / -x / -z → unchanged Already ends in s/x/z: le pays → les pays  |  la voix → les voix
-eau / -au / -eu → + x Add x not s: le bateau → les bateaux  |  le gâteau → les gâteaux
-al → -aux Most -al words: l'animal → les animaux  |  le journal → les journaux
-ail → -aux (some) Only a few: le travail → les travaux  |  le vitrail → les vitraux
-ou → -oux (7 words) Memorize these 7: le bijou → les bijoux  |  le genou → les genoux  |  le chou → les choux
Irregular — memorize l'œil → les yeux  |  le ciel → les cieux  |  monsieur → messieurs
The 7 -ou words that take -x (not -s)
le bijou → bijoux le caillou → cailloux le chou → choux le genou → genoux le hibou → hiboux le joujou → joujoux le pou → poux
Mnemonic: Bijou Caillou Chou Genou Hibou Joujou Pou — "BCCGHjP"
